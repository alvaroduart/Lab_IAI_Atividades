● Atividade 01: Perceptron Simples

Classificação automática da pureza de destilação fracionada de óleo (Classes C1 e C2) utilizando Hebb Supervisionado.

Definição do Modelo

O Perceptron é a unidade básica de decisão linear. Dada uma entrada $X$, calcula-se a soma ponderada de seus elementos ponderados por pesos sinápticos $W$ mais um viés (bias) $w_0$:

v = w₀ + w₁x₁ + w₂x₂ + w₃x₃

A saída da rede $y$ é determinada aplicando a função sinal (limiar rígido):

y = sgn(v) = { +1 se v ≥ 0, -1 se v < 0 }

● Atividade 02: Rede ADALINE

Controle de envio automático de ajuste de duas válvulas com algoritmo de Regra Delta de convergência global.

Definição do Modelo

Ao contrário do Perceptron, o ADALINE (Adaptive Linear Neuron) calcula seu erro utilizando o sinal linear contínuo, antes de aplicar o limiar rígido. A Regra Delta minimiza o Erro Quadrático Médio (EQM):

E = ½ ∑ (d_k - w^T x_k)²

A superfície do erro em relação aos pesos forma um hiperparaboloide, possuindo um único mínimo global. Portanto, independentemente da inicialização aleatória, os pesos finais convergem exatamente para a mesma configuração ótima.

● Atividades 03, 04, 05: Multicamadas (PMC)

Estimador universal de funções e classificador não-linear usando Backpropagation, Momentum e Time Delay (TDNN).

Conceitos Fundamentais

  • Aproximação Universal: Redes de múltiplas camadas conseguem criar superfícies de decisão altamente não-lineares, contornando a limitação de separabilidade linear.
  • Backpropagation: Propaga o erro da saída de volta para as camadas ocultas, atualizando os pesos por gradiente descendente.
  • Fator de Momentum (α): Adiciona um termo de inércia para acelerar a convergência e evitar oscilações em vales estreitos.
  • TDNN (Time Delay): Utiliza uma janela deslizante temporal para prever séries temporais de mercados financeiros.

● Atividades 06, 07: Redes RBF

Mapeamento de injeção eletrônica e classificação de radiação nuclear utilizando Funções de Base Radial baseadas em proximidade local.

Definição do Modelo

A arquitetura RBF (Radial Basis Function) utiliza neurônios ocultos com ativações Gaussianas centradas em clusters específicos do espaço. A ativação depende da distância euclidiana da entrada $x$ ao centro do cluster $c_i$:

φ_i(x) = exp( - ||x - c_i||² / (2σ_i²) )

A camada oculta mapeia a entrada de forma não-linear, enquanto a camada de saída executa uma combinação linear ponderada simples (treinada via Regra Delta).

● Atividade 08: Memória Associativa de Hopfield

Recuperação de padrões digitais ruidosos de dígitos de 45 bits utilizando dinâmica energética de convergência assíncrona.

Teoria e Limitações

A rede de Hopfield armazena memórias no formato de mínimos locais de energia. A energia global é definida por:

E = - ½ ∑ w_ij s_i s_j

Seus pesos são calculados usando a matriz hebbiana:

w_ij = ½ ∑ ξ_i¹ ξ_j¹ + ξ_i² ξ_j² ...

Bacias de Atração: Quando um padrão ruidoso é inserido, o sistema executa atualizações assíncronas até "rolar" para o fundo de uma bacia de atração. Se o ruído for alto demais (>25%), ou se as memórias forem estruturalmente próximas (como o Dígito 2 e 3 que diferem por apenas 8 bits), a rede pode cair em estados espúrios ou retornar o padrão em negativo.

● Atividade 09: Mapa de Kohonen (SOM)

Redução de dimensionalidade espacial e mapeamento topológico bidimensional não-supervisionado.

Definição do Modelo

O Self-Organizing Map (SOM) de Kohonen organiza neurônios em uma grade topológica bidimensional (neste caso, 4x4). No treinamento, o padrão vencedor (BMU - Best Matching Unit) atrai seus pesos e os pesos de seus vizinhos geográficos na grade em direção à entrada:

W_i(t+1) = W_i(t) + η(t)[ x - W_i(t) ]

Mapeamento das Classes A, B, C: O SOM conseguiu agrupar o dataset do lab em clusters nítidos na grade 4x4. Neurônios vizinhos representam classes idênticas ou similares.

● Atividade 10: Rede LVQ-1

Classificação supervisionada de perfis diários de demanda de potência elétrica.

Configurações e Resultados

A Learning Vector Quantization (LVQ-1) utiliza protótipos de classes para definir fronteiras de decisão supervisionadas. Se o protótipo vencedor pertence à classe correta, ele é aproximado do padrão de entrada. Se pertencer à classe incorreta, é repelido.

Resultados Finais: Ambos os cenários de inicialização (média vs primeira amostra) convergiram para as mesmas classes exatas nos 8 dias de teste. Os protótipos se posicionam perfeitamente na média das curvas de carga do treinamento.

● Atividade 11: Rede ART-1

Agrupamento não-supervisionado de status de processos industriais sob limiares variáveis de vigilância.

Dilema da Estabilidade-Plasticidade

A rede ART-1 resolve o dilema de aprender novas informações (plasticidade) sem apagar categorias consolidadas (estabilidade). O grau de vigilância $\rho$ controla o quão rígida é a tolerância a diferenças:

||x ⊙ t_J|| / ||x|| ≥ ρ

Se a similaridade do protótipo vencedor $t_J$ com a entrada $x$ atinge $\rho$, ocorre a ressonância (aprendizado). Caso contrário, a categoria é inibida temporariamente, reiniciando a busca. Se nenhuma categoria comprometida passar, cria-se uma nova classe.
