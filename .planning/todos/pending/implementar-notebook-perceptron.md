# Criar o Jupyter Notebook base e implementar a classe Perceptron

Tarefa inicial para a Atividade 01.

**Passos:**
1. Inicializar o arquivo Jupyter Notebook na pasta do projeto.
2. Criar a classe `Perceptron` com construtor (inicialização de pesos e viés), método de treinamento (regra de Hebb supervisionada) e método de predição (função degrau bipolar).
3. Importar a base de dados do anexo (30 padrões de treinamento).
