# Decisões de Arquitetura

Decidimos seguir com a seguinte estrutura para a resolução da Atividade 01:
- **Ambiente:** Jupyter Notebook para mesclar código executável e respostas textuais/tabelas num mesmo relatório.
- **Abordagem Técnica:** Implementação Orientada a Objetos de uma classe `Perceptron` a partir do zero.
- **Bibliotecas:** Uso restrito da linguagem Python pura e do `numpy` para as operações matemáticas com matrizes. O uso de bibliotecas de Machine Learning com o Perceptron pré-implementado (como scikit-learn) é expressamente proibido pelos requisitos.
- **Estrutura:** O Notebook deve conter carregamento de dados, a classe do algoritmo, loop de treinamento (5 vezes com pesos aleatórios), classificação de novas amostras gerando tabelas, e respostas Markdown para as perguntas teóricas.
